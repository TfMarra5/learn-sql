# Consultar tabelas

Uma base de dados contém tabelas. Cada linha representa um registo e cada coluna uma característica. SQL descreve o resultado que procuras.

SELECT escolhe as colunas; FROM indica a tabela. O asterisco (*) mostra todas as colunas. Termina cada instrução com ponto e vírgula. As palavras-chave podem ser escritas em minúsculas, mas vamos usar maiúsculas para facilitar a leitura.

```sql
SELECT id, nome FROM produtos;
```

Esta consulta mostra duas colunas dos produtos. Não altera os dados. Sem ORDER BY, a ordem das linhas não é garantida.
